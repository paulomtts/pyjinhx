# Theme Tokens

This table lists every token the default theme sheet (`pyjinhx/client/pjx_theme.css`) defines, with its light and dark value. It is generated from the sheet when the docs are built, so it always matches what ships.

A `—` in the Dark column means the token has one value in both modes.

See the [theming guide](../guide/theming.md) for how to turn the theme on and override tokens.
